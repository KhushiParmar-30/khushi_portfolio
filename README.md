# Khushi Parmar Portfolio

A modern React + Vite + Tailwind CSS portfolio for Khushi Parmar.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Replace later

- `src/data/portfolio.js` — portfolio content
- GitHub / LinkedIn placeholder links in `Hero.jsx`
- Project GitHub / Live Demo placeholders in `ProjectCard.jsx`
- `public/resume/Khushi_Parmar_Resume.pdf` — resume PDF
